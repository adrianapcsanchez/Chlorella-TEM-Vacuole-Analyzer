# Suggested Materials and Methods text

## TEM image analysis and vacuole quantification

Transmission electron microscopy (TEM) images were analyzed using the **TEM Vacuole Area Analyzer**, a custom Python-based semi-automatic image-analysis workflow developed for this study (Adriana Pereira C. Sánchez, 2026). Images were subjected to grayscale brightness/contrast normalization before segmentation. Spatial calibration was obtained from the scale information displayed in the lower-left region of the TEM images. The software attempts to detect the scale bar and read its printed value by optical character recognition (OCR); when automatic calibration is unsuccessful, manual calibration can be performed by entering the scale value and marking the scale-bar endpoints.

Cells were automatically segmented from the TEM background using grayscale contrast followed by morphological filtering and refinement of the external cell contour. Intracellular vacuole candidates were then automatically pre-detected using geometric, local grayscale, texture, and morphological criteria. Because TEM contrast and intracellular organization vary among cells and images, every processed image was subsequently reviewed interactively before quantitative export. Automatically proposed vacuole contours could be retained or deleted, while missing vacuoles could be added either by seed-guided region growing initiated from a user click or by manual boundary drawing. Reviewed vacuole regions were constrained to the corresponding cell mask.

For each reviewed cell, the software calculated cell area, number of vacuoles, summed vacuole area, and the ratio of total vacuole area to cell area. When spatial calibration was available, areas were additionally converted from pixels squared to micrometers squared. Annotated verification images displaying cell boundaries in green and reviewed vacuole boundaries in red were generated for quality control. Cell-level measurements and image-level summaries were exported to Excel, and annotated images were compiled into a PowerPoint report for visual verification.

The source code, documentation, parameter descriptions, and citation information are provided in the **Chlorella-TEM-Vacuole-Analyzer** repository (Pereira C. Sánchez, 2026). The permanent repository URL and, if applicable, archived software DOI should be inserted in the final manuscript version.
