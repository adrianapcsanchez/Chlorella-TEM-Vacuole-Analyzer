"""
====================================================================
 VACUOLE ANALYZER FOR C. vulgaris CELLS - v34 AUTOMATIC REVIEW (TEM images)
====================================================================

What this script does:
 1. Asks you to select the folder containing the images (.tif/.tiff/.png/.jpg).
 2. Displays a window where you can REVIEW/ADJUST the
    segmentation parameters (you do not need to edit the code; see the "PARAMETERS" section
    below).
 3. Asks whether you want to calibrate vacuole recognition by clicking
    an example (recommended the first time you use a new image batch
    or whenever the vacuoles are gray/low-contrast
    and are not recognized with the default values).
 4. For each image:
      a) Calibrates image brightness/contrast to a common standard (assim
         fotos mais claras e mais escuras do mesmo tipo de amostra sao
         tratadas de forma equivalente).
      b) Le o numero da escala (ex.: "1 um", "500 nm") no canto inferior
         esquerdo da foto via OCR, e calcula a calibracao usando um
         comprimento de barra FIXO (a barra sempre mede entre ~450 e
         ~600 pixels nessas fotos, entao um valor fixo de referencia e
         suficiente e muito mais robusto do que tentar detectar o
         comprimento exato em cada imagem).
      c) Segments the cell(s) in the image (pode ter de 1 a 4 celulas).
      d) Runs automatic vacuole detection, then opens every image for review.
         A adds from one click, B draws a boundary, and C erases a contour.
      e) Calculates each cell area, each vacuole area, the sum
         of vacuole areas, and the vacuole/cell ratio (%).
      f) Creates a verification image with a GREEN cell outline and
         RED outlines around detected vacuoles.
 5. At the end, it generates:
      - An Excel spreadsheet (.xlsx) com todos os dados (uma linha por
        celula encontrada).
      - A PowerPoint presentation (.pptx) com 2 fotos anotadas por
        slide (lado a lado), cada uma com o nome do arquivo em cima e a
        tabela de dados daquela foto embaixo, para conferencia visual.

------------------------------------------------------------------
 IMPORTANT - ABOUT AUTOMATIC RESULTS
------------------------------------------------------------------
Automatic TEM image segmentation is never 100% perfect. POR ISSO
o script sempre gera as imagens anotadas (verde/vermelho) e o
PowerPoint: use-os para conferir visualmente cada resultado antes de
usar os numeros em uma publicacao.

------------------------------------------------------------------
 INSTALLATION (run once in a terminal/command prompt)
------------------------------------------------------------------
pip install numpy opencv-python tifffile imagecodecs pytesseract pandas openpyxl python-pptx pillow matplotlib

Alem disso, o pytesseract precisa do programa Tesseract-OCR instalado
no computador (nao e so uma biblioteca Python):
  - Windows: baixar o instalador em
    https://github.com/UB-Mannheim/tesseract/wiki  e instalar.
    Depois, se o script nao achar o tesseract sozinho, defina o
    caminho manualmente na CONFIG abaixo (TESSERACT_CMD).
  - Mac: brew install tesseract
  - Linux: sudo apt install tesseract-ocr

Se voce nao quiser instalar o Tesseract, o script ainda funciona: ele so
vai pedir pra voce DIGITAR o valor da escala (em vez de ler sozinho) em
toda imagem cujo texto nao conseguir reconhecer.
====================================================================
"""

import os
import re
import sys
import json
import traceback
import shutil
from pathlib import Path

import numpy as np
import cv2

# ---------------------------------------------------------------
# PARAMETERS - valores default (podem ser ajustados pela window do
# programa, sem precisar editar este file; veja editar_parametros_gui)
# ---------------------------------------------------------------
class CONFIG:
    # Caminho do executavel do tesseract (deixe None para autodetectar).
    # Exemplo Windows: r"C:\Program Files\Tesseract-OCR\tesseract.exe"
    TESSERACT_CMD = None

    # --- calibration de brightness/contraste entre datasets ---
    # Cada conjunto de images pode ter um "brightness geral" diferente -
    # umas fotos mais claras, outras mais escuras. Essa calibration
    # estica o histograma de CADA foto para uma faixa de referencia
    # comum ANTES de segmentar, para que os mesmos parameters funcionem
    # de forma equivalente em qualquer conjunto.
    CALIBRAR_BRILHO = True
    BRILHO_PERCENTIL_BAIXO = 1     # MENOR = mais sensivel a pixels de ruido bem escuros
    BRILHO_PERCENTIL_ALTO = 99     # MAIOR = mais sensivel a pixels de ruido bem claros
    BRILHO_REF_BAIXO = 8           # para onde o percentil "baixo" e esticado (0-255)
    BRILHO_REF_ALTO = 245          # para onde o percentil "alto" e esticado (0-255)
    AUTO_GAMMA = True              # clareia automaticamente imagens realmente escuras
    AUTO_GAMMA_TARGET_MEDIAN = 145 # mediana-alvo apos normalizacao
    AUTO_GAMMA_TRIGGER_MEDIAN = 125# so aplica gamma se a imagem continuar escura
    AUTO_GAMMA_MIN = 0.68          # limite para nao superclarear a imagem

    # --- segmentation da cell ---
    CLAHE_CLIP = 2.0              # MAIOR = mais contraste local realçado (pode aumentar ruido)
    CLAHE_TILE = 16               # tamanho dos blocos do realce local de contraste
    GAUSS_BLUR_CELL = 11           # MAIOR = mais suavizacao antes de decidir celula/fundo
    DENOISE_MIN_COMPONENT_FRAC = 0.0003  # MAIOR = remove manchas maiores como "sujeira" antes de unir a celula
    CLOSE_KERNEL_CELL = 91        # MAIOR = une pedacos mais distantes da MESMA celula (mas pode
                                    # tambem soldar 2 cells proximas numa so se for grande demais)
    OPEN_KERNEL_CELL = 9          # MAIOR = remove tentaculos/pontes finas mais grossas ligando a
                                    # cell ao fundo (mas pode cortar partes finas legitimas da cell)
    MIN_CELL_AREA_FRAC = 0.01     # MENOR = aceita celulas menores (fracao da area da imagem)
    MAX_CELL_AREA_FRAC = 0.85     # MAIOR = aceita celulas maiores (ate esse % da imagem)
    MIN_CELL_SOLIDITY = 0.75      # MAIOR = exige celula mais "arredondada/preenchida" (descarta
                                    # riscos e dobras de resina, mas pode rejeitar cells com
                                    # reentrancias legitimas)
    MAX_CELL_ASPECT_RATIO = 2.5
